# Folder Organizer

Give folders distinct colors and recognizable icons, keep favorites close, and create a tidy project structure in one Unity Editor window.

## Open

Choose **Tools > Sakanfar Productions > Folder Organizer**, or right-click a folder and choose **Folder Organizer > Colors and Icons...**.

The window uses Unity's native editor fonts and controls, with no external fonts or stylesheets.

## Colors

Select one or more folders in the Project window, then click a color swatch to apply it instantly. There are 16 presets. **Custom color** opens Unity's full color picker, including its eyedropper. You can also type a **Hex color**, such as `#5C9FF5`, and press Enter.

**Reset color** restores Unity's folder color and keeps the icon and favorite. Colors tint the folder image, leaving its name readable.

## Icon presets

Click a labeled icon tile to apply an image badge: **C# Scripts**, **Prefabs**, **Scenes**, **Materials**, **Textures**, **Audio**, **Models**, **Shaders**, **Art**, **UI**, **Editor**, **VFX**, **Settings**, **Plugins**, or **Documentation**.

The preview shows the selected folder's color and icon. Icons appear inside the folder image in both Project list and grid views; no text is drawn over folder names. **No icon** removes the badge and keeps the color. Audio uses music notes, VFX a sparkle, Settings a gear, Art a paint palette, and Plugins an electrical plug. These five original icons are generated by the package and do not depend on Unity icon names or optional modules. Other presets use the installed Unity Editor icons, with a generic asset fallback when unavailable.

Colors, icons and favorites can be changed independently. Use **Ctrl+Z** (Windows/Linux) or **Cmd+Z** (macOS) to undo an appearance change. Multiple selected folders receive the same change. Selecting a file disables folder actions.

## Favorites

Click **Favorite selection** to pin selected folders. Click a shortcut to select and ping its folder. **Remove** removes only the shortcut; it does not delete the folder or its color/icon. A small gold marker identifies favorites in the Project window.

## Create folders

Expand **Create a project folder structure**. Enter the root name (default: `_Project`), choose the folders you need, and click **Create folders**. The defaults are Scenes, Scripts, Prefabs, Art, Audio, and UI. Missing folders are created under `Assets`; existing folders and files are kept.

## Installation and project data

Import the release `.unitypackage`. Keep the package at `Assets/Sakanfar Productions/Folder Organizer`, where its guide and project database are loaded.

The appearance database is created automatically in `Editor/Data/FolderAppearanceDatabase.asset`. Commit it with your project to share colors, icons and favorites. The release excludes development styles and settings. Styles use folder GUIDs and follow renames and moves made inside Unity.

Older releases used a hidden native cache. This version retains its original ScriptableObject type solely to dispose of leftover cache objects during editor reload. New drawing state uses a separate managed class and no InstanceID APIs. If an error from before the update remains in the Console, clear it after recompilation; if Unity could not reload the old state, close and reopen the editor once.

This is an editor-only tool with no runtime or render-pipeline dependency. See the release validation notes for tested Unity versions.
